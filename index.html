About

Kernel 17 is an open source kernel for scratch operating systems. Developed by by Microzeg for use
in the Scratches Operating System, it has all the features you need to start developing your own OS.
You can download it here.

The purpose of this Project

The purpose of Kernel 17 is to make a lightweight but efficient kernel for scratch-based operating system.
Originally developed as a proprietary kernel for Scratches, we decided to release a public
version for anybody to use as a basis for their operating system.

The future of this project

We will continue to open source kernel 17 as it develops,
including an upcoming 2.0.0 version coming with Scratches 18.
